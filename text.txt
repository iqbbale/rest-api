WEB API / WEB SERVICE
" adalah sebuah sistem perangkat lunak yang dibuat untuk mendukung interoperabilitas / interaksi antar 2 aplikasi yang berbeda melalui jaringan " ( biasnya nanti jaringanyna mengunakan http protocolnya )

WEB API dan WEB SERVICE berbeda dalam cakupan dan flexibilitas, 
WEB API adalah antarmuka umum untuk interaksi applikasi (bisa lokal /jaringan, format JSON/XML)
sedangkan WEB SERVICE adalah subset khusus API yang wajib mengunakan jaringan (HTTP) dan standart ketat seperti SOAP
semua web service adalah API namun tidak semua API adalah web server

JSON : 
apa itu json? 
json adalah sebuah file format standart yang mengunakan tulisan yang dapat dibaca oleh manusia untuk pertukaran data yang di dalamnya berisi pasangan antara key dan value

Json itu format pertukaran data tekstual yang sangat ringan sintaks sangat sederhana dan jelas dibanding (XML)
dapat digunakan pada beragam bahasa pemrograman
tiap bahasa pemrograman memiliki cara sendiri untuk berinteraksi dengan JSON

Json di buat berdasarkan format object pada js
digunakan untuk file konfigurasi(tidak disarankan) karena tidak suport syntax komentar
Tipe file JSON memiliki ekstensi .json
Fortmat JSON dibuat dan diusulkan oleh Douglas crockford

jika mau mencari tahu bedanya XML & JSON LIAT DI SCRENSOT

Object itu adalah sebuah kumpulan property dan propertynya ditulis dalam pasangan key dan value

JSON itu tida boleh ada method, hanya boleh key & value

key selalu dibungkus "",
jika value : bolean, array, string, object dalam object, Number, Null
Singkat menjadi : BASONN,
agar json type datanya basonn

dalam json tidak bisa sebuah data itu 2, hanya bisa dilakukan ketika data tersebut dikonfigurasi ke dalam array

jika mengunakan json di luar domain, atau luar drive
itu ada yang namanya same-origin policy 
kebijakan browser untuk mengakses dan menampilkan / script / document dari tempat lain diluar domainnya
membuat kita tidak bisa mengakses data (.json) dari luar domain / website kita
nanti ada penolakan yang namanya CORS
CORS ( Cross Origin Resource Sharing ), ini adalah mekanisme yang membuat kita dapat mengakses sebuah resource (data,document,script) dari domain lain
caranya adalah ubah konfigurasi server memperbolehkan adanya akses data luar domain
modifikasi Access-Control-Allow-Origin
membuat file (.htaccess)
buat file di dalamnya seperti ini :
<IfModule mod_headers.c>
	Header set Access-Control-Allow-Origin "*"
</IfModule>
ini akan kepakai ketika bikin rest servernya
